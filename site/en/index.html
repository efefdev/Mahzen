Security

Everything you see is encrypted.
So is everything you don't.

File contents, file names, folders, notes and passwords are encrypted before they ever leave this computer. All that's left on disk are randomly named files full of random-looking bytes.

256bit
AES-GCM encryption, with a separate key for every file.
1GB
The memory Argon2id demands for every password guess. Guessing in bulk gets expensive.
0servers
No account, no cloud, not a single byte sent to the internet.

Inside

Everything private.
In one place.

Files

Drag and drop. Folder structure is preserved, and files are encrypted as they're added. Images and text open right inside the app; a duplicate file is never added twice.

Notes

Recovery phrases, passport numbers, half-finished plans. Color them, pin them, search them.

Passwords

Accounts, cards, Wi-Fi, servers. It generates strong passwords and measures their strength, and clears a copied password from the clipboard after 30 seconds.

Locks itself

It locks when you're idle, when the computer sleeps, when the screen locks and the moment the SSD is unplugged. The keys are wiped from memory.

Wrong-password limit

Five wrong passwords.
Then nothing.

If you turn it on, Mahzen destroys its own keys once the number of consecutive wrong passwords you chose has been entered. Nothing in the vault can ever be opened again, not even with the right password.

  • 3–99attempts; turn it on or off whenever you like
  • Attempts leftshown on the lock screen, reset by the right password
  • One countershared by macOS, Linux and the command line

macOS and Linux

One vault. Two worlds.

Put the vault on an SSD and open it on a Mac or on Linux. A file you add on one is right there on the other.

macOS · SwiftUI   /   Linux · GTK 4 + libadwaita

Step into the vault.

macOS 14+ · Xcode 15.3+

git clone https://github.com/efefdev/Mahzen.git
cd Mahzen
./scripts/build-app.sh

Linux GTK 4 · libadwaita 1.5+

git clone https://github.com/efefdev/Mahzen.git
cd Mahzen/linux
./install.sh

Mahzen has not yet been through an independent security audit. Its building blocks are audited libraries; the code that puts them together is not. If you find a vulnerability, report it. If you forget your password, your data cannot be recovered; there is no backdoor.
